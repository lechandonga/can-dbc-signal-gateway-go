# can-dbc-signal-gateway-go

一套**完全本地可运行**的 CAN 信号解析与车辆状态维护组件：可直接喂入真实工具导出的
DBC 原样文件，支持按信号注入造帧与一个进程内多路总线并存；总线帧由本地确定性帧序列
模拟，不依赖真实硬件或外部服务。对畸形定义、异常帧、注入矛盾、信号失效与运行中更新
定义，结论稳定、可解释、可复现。

## 结构

- `internal/model` — 报文/信号/状态/数值表的不可变数据模型
- `internal/dbc` — 严格 DBC 子集解析、结构校验与导入摘要（采用/忽略/拒绝）
- `internal/canbus` — 帧模型、Intel/Motorola 位编解码、有符号二补码、缩放偏移、拒绝原因
- `internal/cansim` — 本地帧序列脚本与按定义构造帧的 Builder（含截断/未知帧辅助）
- `internal/gateway` — 解码、按信号注入、每信号状态维护、超时/复用失效判定、原子热加载
- `internal/fleet` — 多路总线管理器（独立定义/状态/超时/统计、按名分发、故障隔离）
- `cmd/demo` — 端到端本地演示
- `testdata/` — 示例定义与两种工具导出的同义真实文件（含枚举数值表、复用报文）
- `docs/` — 支持子集与边界、解码/注入/失效/热加载规则、多路语义、本地复现指南

## 快速开始

```bash
go run ./cmd/demo                                   # 端到端演示
CGO_ENABLED=1 go test -race ./...                   # 全部测试（竞态检测）
CGO_ENABLED=1 go test -race ./... -v                # 分业务/输入/判定的结构化日志
```

## 关键语义（详见 docs/）

- **非法定义不静默跳过**：一次解析返回 `dbc.ErrorList`，收集全部错误；
  每条带行号、报文、信号与可区分 `Reason`。
- **采用/忽略/拒绝有摘要**：`dbc.ParseDetailed` 返回 `Summary`，列出被采用的
  报文/信号、被明确忽略且不影响解码的构造（含原因）、被拒绝的位置与理由。
- **真实导出直接接入**：断行、空白、分号、注释、属性、具名/内联数值表、扩展帧 ID
  等等价写法解析结果一致；数值表在查询时给出原始值+标签，未收录稳定回退原始值。
- **混排字节序边界明确**：两种字节序真正共位 -> `BIT_OVERLAP` 定位到报文/信号；
  相邻不冲突 -> 正常加载且逐位解码正确。
- **按信号注入**：`Inject` 以最后接受帧原始位为基帧（从未收到为全 0 默认帧），
  只改指定信号，构帧后走同一解码链路；复用三类矛盾（选择值非法 / 布局对不上 /
  无布局）分开拒绝；切换后旧布局信号为独立的 `MUX_INACTIVE`，不与超时混淆。
- **异常帧不污染状态**：未知报文 / 未知信号 / 长度不符 / 截断 / 非法复用 / 超范围 /
  时间戳回退各自返回可区分原因，操作被整体拒绝，不留半成品。
- **失效可配置**：默认超时 + 按信号覆盖；持续无更新判 `TIMEOUT`，来帧即恢复；
  `NEVER_RECEIVED` 与"信号不存在"严格区分。
- **热加载原子**：新定义先完整解析，失败整体拒绝且旧定义继续服务；成功后写锁内
  一次性替换，观察者永远看不到新旧混用。
- **多路隔离**：每路独立定义/状态/超时/统计；一路失败不影响其它路；未知总线名
  返回可区分 `*fleet.BusError`；`Summary()` 与逐路查询一致；单路 `gateway` 用法不变。
- **可复现**：不使用墙上时钟；帧时间戳与查询 `now` 均由调用方提供。
